A program that writes one dad joke to /output/entry.txt for make.fun's "Dad Joke Showdown" bounty. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes a single dad joke (156 characters) to /output/entry.txt, or to $MAKEFUN_OUTPUT_DIR/entry.txt when that is set. It is deterministic: every run writes the same bytes.
